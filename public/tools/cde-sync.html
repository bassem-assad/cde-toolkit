CDE Sync

Move files into ACC from your other systems, named and tagged to your standard.

Try the demo Request a pilot Autodesk sign-in

Who it's for

  • BIM and information managers moving a project into ACC from ProjectWise, SharePoint, InEight Document or another ACC project.
  • Document controllers who want files to arrive with the right name and metadata, not fixed afterwards.
  • Consultants and contractors bringing a project's files into their own ACC hub.

Why it helps your company

  • Files arrive conformingNames and attributes are checked and corrected on the way in, so there is less clean-up after migration.
  • No silent surprisesEvery skipped or flagged file has a stated reason, and you decide what happens to values that don't fit.
  • A record you can shareThe results CSV lists each file, its final name and what happened to it.
  • No migration server to hostIt runs in the browser, so there is nothing to install or maintain on your side.

What it does

The steps

  1. Source
  2. Destination
  3. Files
  4. Attributes
  5. Naming
  6. Review
  7. Results

Nothing is sent until you press Start transfer on the Review step.

  • Reads files from ProjectWise, SharePoint, InEight Document, another ACC project, or a folder on your computer.
  • Reads the naming standard applied to the destination ACC folder (or lets you define one), then shows which files match, which can be fixed by mapping, and which cannot.
  • Lets you drag the parts of a file name onto the standard's fields, set fixed values, swap a value for one from the ACC droplist, and correct individual files.
  • Maps source attributes to ACC attributes and flags type differences (text, droplist, date, number) before anything is sent.
  • Renames files to the standard and fills ACC attributes from the file name, if you choose.
  • Asks what to do with values that don't fit: leave blank, skip the file, or add the value to the droplist.
  • Uploads each file as new or as a new version of an existing file, then shows a results dashboard (passed, warnings, failed, skipped) with a CSV export.
Example scenario

A team moves 400 drawings from ProjectWise into a new ACC project. The destination folder has a six-field naming standard and droplists for discipline and status. CDE Sync flags the files whose names don't have six parts, lets the team map the rest, and adds one agreed status value to the droplist. The results CSV goes to the document controller.

What you need

  • An Autodesk sign-in, a hub on a full Forma plan, and permission to upload to the destination folder.
  • ProjectWise: the Web API address and a login. Your ProjectWise server must allow the toolkit's web address (CORS).
  • SharePoint: a one-off Microsoft Entra app registration with read permission for files and sites.
  • InEight Document: the API base URL and a key or token. InEight's API paths are not published openly, so the tool lets you edit them; an export loaded from your computer works too.
  • A naming standard on the destination folder helps, but you can define one inside the tool.

See the requirements for hub plans, and the admin guide for the one-off setup.

Good to know

  • It transfers one folder at a time.
  • Files pass through your browser (downloaded, then uploaded), so keep the tab open and allow time for large files.
  • Try it on a test folder first.
