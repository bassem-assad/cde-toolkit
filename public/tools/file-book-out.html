File Book Out

Control who is working on a drawing, with a book-out request in a few clicks.

Try the demo Request a pilot Autodesk sign-in

Who it's for

  • Document controllers and information managers who run a book-out (check-out) process for drawings.
  • Teams that want to reduce the risk of two people working on the same drawing.

Why it helps your company

  • Fewer conflicting editsFiles that are already booked out are caught before a second request is made.
  • Consistent requestsReview names follow the same pattern every time.
  • No huntingSearch by attribute across subfolders instead of opening each one.

What it does

  • Searches a folder and all its subfolders by attribute values and by file name.
  • Groups files by drawing, so the PDF, DWG and model of one drawing are handled together.
  • Shows each file's booking status and leaves out files that are already booked out, listing them for you.
  • Names the review automatically from a prefix you set plus the files' location code (one location code per review).
  • Lets you choose the review template, then creates the ACC review with the selected file versions.
Example scenario

An engineer needs to update three drawings for one location. They search by location, tick the sets, add them to the basket and start the review from the book-out template. Two files already booked out by a colleague are listed and left out.

What you need

  • An Autodesk sign-in and permission to start reviews.
  • Reviews with a workflow template. You set the words the tool looks for in the template's name (the default is "book out").
  • A location code attribute and a booking status attribute on your files. You set their names, the status value that means "booked out" and the review name prefix in Settings.

See the requirements for hub plans, and the admin guide for the one-off setup.

Good to know

  • All files in one review must share a location code, so book out different locations separately.
  • The tool reads the booking status and starts the review. It doesn't change the status itself; your ACC workflow does that.
