File validator

Check a file list against your naming convention and required attributes before it becomes a problem.

Try the demo Request a pilot Excel or CSV export

Who it's for

  • Information managers preparing a project for handover or audit.
  • BIM coordinators checking that suppliers' deliveries follow the BIM execution plan.
  • Document controllers who want a repeatable naming check.
  • Anyone with an export of a file list, including people who don't have ACC access.

Why it helps your company

  • Catch problems earlyFind mis-named or untagged files before handover, audit or a supplier delivery is accepted.
  • Consistent checksThe same rules are applied to every file, every time.
  • Evidence to send backThe CSV report tells each supplier exactly which files to fix and why.
  • Open to your whole teamNo sign-in or ACC access is needed, only an export.

What it does

  • Reads an Excel or CSV file list exported from ACC Docs, including its attribute columns.
  • You describe the naming convention part by part: the separator, then for each part either a list of allowed codes or a pattern.
  • Flags a wrong number of parts, codes that aren't allowed, empty parts, and spaces or special characters.
  • Checks that the attributes you mark as required are filled in.
  • Shows pass and fail counts with the reason for every failure, and downloads a CSV report.
  • Remembers your convention in your browser. It starts from a common ISO 19650-style example (project, originator, volume, level, type, role, number).
Example scenario

Before handover, an information manager exports the file list for the Published folder and checks it against the project's naming convention. The report lists every file with a problem and the reason, and the manager sends it to the discipline leads to fix.

What you need

  • An Excel or CSV export of the file list from ACC Docs, with the attribute columns you want checked.
  • No sign-in. The file is read in your browser and is not uploaded anywhere.

See the requirements for hub plans, and the admin guide for the one-off setup.

Good to know

  • It checks file names and attribute completeness, not file contents.
  • It checks one convention at a time.
