Rename

Add the upload date to a Revit model's name, consistently, with a preview first.

Try the demo Request a pilot Autodesk sign-in

Who it's for

  • BIM coordinators and model managers who want models identifiable by the date they were uploaded.
  • Project teams that keep dated model names for coordination records.

Why it helps your company

  • No typing errorsThe date comes from ACC's own upload time, not from someone's memory.
  • The right local dateACC records upload times in UTC. The tool converts to your time zone, so a late-evening upload gets the correct date.
  • See before you changeYou review the exact new name before it is applied.

What it does

  • Browse your hub, project and folders, showing Revit models only (you can switch that off).
  • Shows the current name, the upload time and the version number of the current version.
  • Adds the date as _YYYYMMDD before the file extension, using the Australian time zone you choose.
  • Warns you when a name already ends in a date.
  • Renames the file in ACC with one click and shows the result.
Example scenario

A model uploaded at 8:30 am Melbourne time on 15 September is stored by ACC as the evening of 14 September in UTC. Rename uses the Melbourne time zone, so the file becomes Model_20260915.rvt.

What you need

  • An Autodesk sign-in and permission to rename files in the folder.
  • Models stored in ACC.

See the requirements for hub plans, and the admin guide for the one-off setup.

Good to know

  • It renames the current version. Links to cloud models normally follow the model ID, but test on a copy first and check Manage Links in a host model.
