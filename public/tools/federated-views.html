Federated views

Build a Model Coordination view for each location without clicking through ACC.

Try the demo Request a pilot Autodesk sign-in

Who it's for

  • BIM coordinators and model managers who federate models by location or zone.
  • Project teams that put a location code on every published model.

Why it helps your company

  • Repeatable for every zoneThe same few clicks and the same naming for each location.
  • Fewer mistakesModels are selected from your own attributes, not picked by hand from a long list.
  • Follows your metadataIf a model has the right location code, it appears in the right view.

What it does

  • Finds the project's Published folder and the Model Coordination model set built on it.
  • Reads the latest version of the model set and each model's attributes, then groups the models by location code.
  • Lets you pick a code, then tick or untick models, search, and choose which attribute columns to show.
  • Creates a view named after the code (for example STN-A_FEDERATED) in the model set, and stops if a view with that name already exists.
  • Can create the model set from the folder if there isn't one, and shows the job status and a link to Model Coordination.
Example scenario

A station project has dozens of zones, each with a location code on every published model. Instead of building each view by hand in Model Coordination, the coordinator picks a code, checks the list and creates the view. The next zone is the same few clicks.

What you need

  • An Autodesk sign-in and a hub with Model Coordination available (your admin can confirm).
  • A model set based on your Published folder, and a location code attribute on the models.
  • Permission to create views. You set the Published folder name, the location attribute name and the view suffix in Settings to match your project.

See the requirements for hub plans, and the admin guide for the one-off setup.

Good to know

  • It never overwrites an existing view: it stops and tells you.
  • The results depend on the model set being up to date.
