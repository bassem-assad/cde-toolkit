CDE Toolkit › Admin guide

Add CDE Toolkit to your ACC hub.

A one-off setup for your hub admin, about five minutes. This guide covers the steps, the permissions requested and where your data goes, so your IT team can review it.

Request a pilot Try the demo first

Before you start

  • You are an admin of the ACC (Autodesk Forma) hub.
  • Hub Admin shows a Custom Integrations tab. Autodesk Support notes that this tab is hidden for trial hubs and for hubs on Essentials subscriptions. If you can't see it, the hub can't add integrations.
  • You have the CDE Toolkit Client ID (shown below).
  • You have picked a non-critical project and a few test users for the pilot.

Add the integration

  1. Open Hub AdminSign in to ACC at acc.autodesk.com with your admin account and open Hub Admin.
  2. Open Custom IntegrationsSelect the Custom Integrations tab, then Add custom integration.
  3. Enter the detailsPaste the Client ID below and name the integration, for example CDE Toolkit. Complete any other fields Autodesk shows. Autodesk renames screens from time to time, so labels may differ slightly.
  4. SaveThe integration now appears in the list. Remove it there at any time to cut off access.
  5. Tell your users where to goSend people to /app/. Each person signs in with their own Autodesk account.

CDE Toolkit Client ID

Your contact will provide the Client ID.

What permissions does it ask for?

The toolkit asks for one set of permissions at sign-in, shared by all tools.

PermissionUsed for
data:readRead hubs, projects, folders and files, and their attributes.
data:writeChange files and their metadata, for example when renaming a file or setting attributes.
data:createCreate files, new versions, reviews and Model Coordination views.
data:searchSearch for files within folders.
account:readList the hubs (ACC accounts) the signed-in person belongs to.
bucket:readRead file content from Autodesk storage, so files can be transferred or displayed.
user-profile:readRead the signed-in person's name, shown in GeoFed.
  • The toolkit acts as the signed-in person. It can only see and change what that person can already see and change in ACC.
  • For a project to appear in the hub list, the person needs access to the project's Docs files.
  • Tools that change data (CDE Sync, Rename, File Book Out, Federated views) show what will happen before they do it.

Where does the data go?

CDE Toolkit websiteDelivers the web pages and scripts. Receives no ACC data.
→web pages only
Your browserThe tools run here, signed in as the user.
⇄files, attributes, reviews, sign-in
Autodesk (ACC)Where your project data lives.
Optional sourcesProjectWise, SharePoint or InEight, for CDE Sync only.
  • Sign-in uses OAuth 2.0 with PKCE. There is no client secret. The sign-in token lives in the browser tab's session storage and is cleared when the tab closes or the user signs out.
  • There are no advertising or analytics scripts. The only message we receive is one a person chooses to send through the Contact page, handled by a form service (see Privacy).
  • Your browser also fetches some third-party resources: Google Fonts, library files from cdnjs, and in GeoFed, map tiles from OpenStreetMap and Esri.

Optional sources for CDE Sync

  • ProjectWise. Your server must allow the toolkit's web address (CORS), and users need a Web API address and login.
  • SharePoint. A Microsoft Entra app registration with read permission for files and sites. Your Microsoft 365 admin may need to approve it.
  • InEight Document. An API base URL and a key or token. API paths aren't published openly, so they can be edited in the tool.

Rolling it out

  • Start with a non-critical project and a few people. Use demo mode for training.
  • Test tools that change data on copies first, and keep your own backups.
  • To end a pilot, remove the integration from Custom Integrations.

Troubleshooting

  • The hub or project doesn't appear after sign-in.Check the integration was added in this hub, and that the person has access to the project's Docs files. Autodesk lists a project only when the user can see at least one file in it.
  • There's no Custom Integrations tab.See Before you start. Trial and Essentials hubs hide it. Ask Autodesk or your reseller about moving the hub to a full subscription.
  • Federated views can't find a model set.It needs Model Coordination in your hub and a model set based on your Published folder. The tool can create the model set if you have permission.
  • Autodesk shows a sign-in error page.The web address the tool runs at must match the one registered in the APS app. Contact us and we'll check it.
