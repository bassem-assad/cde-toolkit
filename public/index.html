How it works

One setup step for the ACC admin, then nothing to install.

  1. Admin adds the app

    Your ACC hub admin adds the CDE Toolkit Client ID under Hub Admin, Custom Integrations. It's a one-off step, and it's also your organisation's approval. The admin guide has the steps.

  2. People sign in as themselves

    Each person signs in with their own Autodesk account. The toolkit can only do what that person's ACC permissions already allow.

  3. Work in the browser

    Files go directly between the source system and ACC. Nothing is uploaded to or stored on our servers.

Requirements

Check these before you pilot it.

You need

  • An ACC (Autodesk Forma) hub on a full subscription such as Forma Data Management, Forma Build or Forma Design Collaboration.
  • A hub admin who can add a Custom Integration.
  • Model Coordination, for Federated views.
  • A current version of Chrome or Edge.

Optional sources for CDE Sync

  • ProjectWise and InEight servers must allow the toolkit's web address (CORS).
  • SharePoint needs a one-off Microsoft Entra app registration.
  • Local folders and CSV attribute exports need nothing extra.
Trial and Essentials hubs can't use itAutodesk Support notes that the Custom Integrations tab is hidden for trial hubs and for hubs on Essentials subscriptions. Those hubs can't add CDE Toolkit. Ask your admin whether the tab is visible before you plan a pilot.
Security and data

Built so your files don't pass through us.

  • The toolkit runs in your browser. Files travel between your source system and Autodesk, not through our servers.
  • Sign-in uses Autodesk's OAuth 2.0 with PKCE. There's no client secret and no password is stored.
  • The sign-in token stays in your browser tab and is cleared when you sign out or close the tab.
  • There are no advertising or analytics scripts on this site or in the app.
  • Tools that change data (CDE Sync, Rename, File Book Out, Federated views) show what will happen before they do it. Test on non-critical projects first and keep your own backups.
  • See the admin guide for the permissions requested and a data-flow summary, and the Terms of Use and Privacy pages.
Questions

What teams and IT ask first.

Do you store or see our files?

No. CDE Toolkit runs in your browser. Files travel between your systems and Autodesk, and our servers only deliver the web pages. The only data we receive is a message you choose to send through the Contact page.

How does sign-in work?

Each person signs in with their own Autodesk account using Autodesk's standard OAuth 2.0 with PKCE. There is no shared password and no client secret. The sign-in token stays in your browser tab and is cleared when you sign out or close the tab.

What can it do in our ACC projects?

Only what the signed-in person is already allowed to do in ACC. Tools that change data (CDE Sync, Rename, File Book Out and Federated views) show what will happen before they do it. Test on a non-critical project first and keep your own backups.

Which ACC plans does it work with?

It needs a hub where your admin can add a Custom Integration. Autodesk Support notes that the Custom Integrations tab is hidden on trial hubs and on Essentials subscriptions, so those hubs can't use it. Full subscriptions such as Forma Data Management, Forma Build and Forma Design Collaboration show the tab. Federated views also needs Model Coordination.

What does our ACC admin need to do?

Add the CDE Toolkit Client ID under Hub Admin, Custom Integrations. It is a one-off step. The admin guide has the steps, the permissions requested and a data-flow summary for your IT team.

Can we try it without any risk?

Yes. Demo mode runs every tool on built-in sample data, with no sign-in, and nothing is sent to Autodesk. For a real pilot, use a non-critical project.

Does it work with ProjectWise, SharePoint and InEight?

CDE Sync can read from all three. Your ProjectWise and InEight servers must allow the toolkit's web address (CORS), SharePoint needs a one-off Microsoft Entra app registration, and InEight's API paths aren't published openly so the tool lets you edit them. If an API isn't available, load an export from your computer instead.

What happens when Autodesk changes its APIs?

CDE Toolkit depends on Autodesk Platform Services, so Autodesk changes can need updates here. Because it is a website, a fix reaches every user at once, with nothing to reinstall.
