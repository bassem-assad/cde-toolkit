ACC file validator

Check files exported from ACC against your file naming convention and confirm required attributes are filled in. Everything runs in your browser; no files are uploaded anywhere.

1. Load the ACC file list

Export the file list from ACC Docs (Excel or CSV) with the attribute columns included, then drop it here.

Demo mode: sample data, nothing is sent anywhere.

2. Naming convention

Each row is one part of the file name, in order. Leave "Allowed values" empty to accept any text, list codes separated by commas (e.g. ARC, STR, MEP), or enter a pattern between slashes (e.g. /^[0-9]{4}$/).
